# Как запустить «Волк ловит яйца»

На телефон игра ставится как обычное Android-приложение из файла `release/wolf-and-eggs.apk`. Этот же Android-проект потом собирается в пакет для Google Play. Исходники и комментарии в коде на английском.

## Установка APK на телефон

Готовый файл для проверки:

`release/wolf-and-eggs.apk`

Его можно скачать с телефона по ссылке ветки:

https://github.com/IliasNizamutdinov/Game-Nu-pogodi/raw/cursor/nu-pogodi-game-0ef6/release/wolf-and-eggs.apk

1. Откройте ссылку в Chrome на телефоне. Файл скачается в «Загрузки».
2. Нажмите на скачанный `wolf-and-eggs.apk`.
3. Если Android пишет, что установка из этого источника запрещена, нажмите «Настройки» в этом окне и разрешите установку для Chrome или «Файлов». Затем вернитесь и нажмите «Установить».
4. После установки откройте приложение **Wolf and Eggs**.
5. Телефон сам повернёт игру горизонтально: так выглядит широкий корпус.

Интернет для запуска не нужен. Это отладочная сборка для установки вручную. В Google Play её загрузить нельзя: магазин принимает подписанный пакет AAB, его сборка описана ниже.

Собрать APK заново на компьютере, где уже установлены JDK 21 и Android SDK:

```bash
npm install
export ANDROID_HOME=/путь/к/android-sdk
export JAVA_HOME=/путь/к/jdk
npm run apk
```

Новый файл снова появится в `release/wolf-and-eggs.apk`. Его нужно заново скопировать на телефон и установить поверх старой версии.

## 1. Запуск на компьютере

```bash
npm install
npm run dev
```

Откройте в браузере:

http://localhost:5173/Game-Nu-pogodi/

Путь `/Game-Nu-pogodi/` обязателен: так же игра будет открываться на GitHub Pages.

Управление с клавиатуры: Q W A S (четыре позиции волка), P — пауза, M — звук, H — вибрация. Коротким нажатием GAME A или GAME B начинается партия. Долгое удержание подсвечивает рекорд.

## 2. Как открыть на Android

Установите `release/wolf-and-eggs.apk`, как описано в начале этого файла. После установки игра лежит в списке приложений под именем **Wolf and Eggs**.

## 3. Значок приложения

После установки APK значок появляется сам. Отдельно добавлять страницу Chrome на главный экран не нужно.

## 4. Проверка офлайн-режима

Установленный APK уже содержит игру. Включите режим полёта и откройте **Wolf and Eggs**. Партия должна начаться без сети. Рекорд остаётся на этом телефоне.

## 5. Как обновлять игру после изменений

```bash
npm test
npm run apk
```

Новый `release/wolf-and-eggs.apk` снова установите на телефон. Для магазина увеличьте `versionCode` в `android/app/build.gradle` и соберите `bundleRelease`, как в разделе про Google Play.

Сайт GitHub Pages по-прежнему собирается отдельно: `npm run build` и workflow `.github/workflows/pages.yml` при push в `main`.

Локально после сборки:

```bash
npm run preview
```

Адрес: http://127.0.0.1:4173/Game-Nu-pogodi/

## 6. Пакет для Google Play

Файл `wolf-and-eggs.apk` подписан отладочным ключом. Его ставят на телефон для проверки. Google Play такой файл не примет: для магазина нужен Android App Bundle, подписанный вашим загрузочным ключом.

Один раз создайте ключ и не теряйте его. Без этого же ключа обновление в Play не опубликовать.

```bash
keytool -genkeypair -v -keystore android/upload-keystore.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

Рядом положите `android/keystore.properties` по образцу `android/keystore.properties.example`. Пароль и файл `.jks` в git не коммитьте.

Сборка пакета для консоли Play:

```bash
export ANDROID_HOME=/путь/к/android-sdk
cd android
./gradlew bundleRelease
```

Готовый файл:

`android/app/build/outputs/bundle/release/app-release.aab`

Его загружают в Google Play Console в новый выпуск. Идентификатор приложения: `com.iliasnizamutdinov.wolfandeggs`. Сейчас `versionCode` равен 1, `versionName` — 1.0.0. Перед каждым следующим выпуском в Play `versionCode` нужно увеличить.

## 7. Что проверяется автоматически, а что вручную

Автоматически (`npm test`):

- пойманное яйцо даёт ровно 1 очко и не считается дважды;
- промах без зайца — целое штрафное очко, с зайцем — половина;
- три штрафных очка заканчивают игру и останавливают новые яйца;
- сброс штрафов на 200 и 500, в том числе в следующем круге;
- переход 999 → 0 не сбрасывает штрафы и сохраняет рекорд 999;
- схемы лотков «Игры А» и все четыре лотка «Игры Б»;
- смена закрытого лотка не телепортирует уже катящееся яйцо;
- повторный старт не копит таймеры и не задваивает цикл;
- пауза и скрытие вкладки останавливают логику;
- большой простой кадра не проматывает игру;
- рекорд читается после «перезагрузки» и не ломается при порче хранилища;
- кнопки помещаются на узкий и альбомный экран и не пересекают лотки.

Отдельно, если установлен Chrome: `npm run build` и `npm run test:smoke` (мобильный размер окна, пауза, поворот, повторная загрузка без сети).

Вручную на настоящем телефоне стоит проверить:

- установку `wolf-and-eggs.apk`;
- запуск без интернета;
- поворот экрана, вырезы и жесты системы;
- вибрацию и удобство красных кнопок.

# Как запустить «Волк ловит яйца»

Игра — это мобильное HTML5-приложение. На телефоне для проверки собирается один файл `release/wolf-catches-eggs.html`. Исходники и комментарии в коде на английском.

## Файл для проверки на телефоне

После каждой сборки на компьютере выполните:

```bash
npm install
npm run phone
```

Появится файл:

`release/wolf-catches-eggs.html`

Это одна страница со встроенными скриптом и стилями. Её можно скопировать на телефон и открыть без сервера и без интернета.

1. Перекиньте `wolf-catches-eggs.html` на телефон: кабель USB, Telegram, почта или облако.
2. На телефоне откройте файл через Chrome. В «Файлах» или «Загрузках» нажмите на файл и выберите Chrome. Если телефон предлагает другой браузер, всё равно выберите Chrome.
3. Держите телефон горизонтально: картинка — широкий корпус, как у карманной игры. В портрете корпус просто становится меньше, поле не обрезается.
4. Красные кнопки слева и справа двигают волка. Справа сверху: Sound, Buzz, Game A, Game B, Pause.
5. Чтобы поставить ярлык, откройте меню Chrome и выберите «Добавить на главный экран», если пункт есть. Для файла с диска этот пункт бывает скрыт — тогда оставляйте файл в «Загрузках» и открывайте его снова.

Повторная сборка после правок кода — снова `npm run phone` и заново скопируйте файл на телефон. Старый файл на телефоне сам не обновится.

Отдельный APK эта команда не создаёт.

## 1. Запуск на компьютере

```bash
npm install
npm run dev
```

Откройте в браузере:

http://localhost:5173/Game-Nu-pogodi/

Путь `/Game-Nu-pogodi/` обязателен: так же игра будет открываться на GitHub Pages.

Управление с клавиатуры: Q W A S (четыре позиции волка), P — пауза, M — звук, H — вибрация. Коротким нажатием GAME A или GAME B начинается партия. Долгое удержание подсвечивает рекорд.

## 2. Как открыть на Android

После публикации сайта откройте в Chrome адрес страницы репозитория GitHub Pages (после включения Pages и успешного деплоя из ветки `main`). Пока деплой не подтверждён, рабочий адрес публикации указывать нельзя.

Для проверки с телефона в одной сети можно использовать локальный dev-сервер, если он доступен по IP компьютера. На самом телефоне удобнее установленная версия с GitHub Pages.

## 3. Установка на главный экран

1. Откройте игру в Chrome на Android.
2. Меню браузера → **Установить приложение** или **Добавить на главный экран**.
3. Запустите значок **Wolf & Eggs**. Окно открывается отдельно от вкладок браузера.
4. Первый запуск должен быть онлайн, чтобы скачались файлы.

## 4. Проверка офлайн-режима

1. Один раз откройте игру при включённом интернете и дождитесь полной загрузки.
2. Включите режим полёта.
3. Откройте игру снова с главного экрана или обновите вкладку.
4. Поле, кнопки и новая партия должны работать без сети. Рекорд остаётся в этом браузере.

## 5. Как обновлять игру после изменений

```bash
npm test
npm run build
```

Закоммитьте и запушьте изменения. После слияния в `main` workflow `.github/workflows/pages.yml` собирает проект и публикует `dist`, если в настройках репозитория источник Pages — **GitHub Actions**.

На телефоне установленная версия подхватит новый service worker при следующем онлайн-открытии.

Локально после сборки:

```bash
npm run preview
```

Адрес: http://127.0.0.1:4173/Game-Nu-pogodi/

## 6. APK

`npm run phone` собирает HTML-файл для Chrome, не APK. Нативного пакета в репозитории нет: для него нужен Android SDK. Для проверки на телефоне используйте `release/wolf-catches-eggs.html`.

## 7. Что проверяется автоматически, а что вручную

Автоматически (`npm test`):

- пойманное яйцо даёт ровно 1 очко и не считается дважды;
- промах без зайца — целое штрафное очко, с зайцем — половина;
- три штрафных очка заканчивают игру и останавливают новые яйца;
- сброс штрафов на 200 и 500, в том числе в следующем круге;
- переход 999 → 0 не сбрасывает штрафы и сохраняет рекорд 999;
- схемы лотков «Игры А» и все четыре лотка «Игры Б»;
- смена закрытого лотка не телепортирует уже катящееся яйцо;
- повторный старт не копит таймеры и не задваивает цикл;
- пауза и скрытие вкладки останавливают логику;
- большой простой кадра не проматывает игру;
- рекорд читается после «перезагрузки» и не ломается при порче хранилища;
- кнопки помещаются на узкий и альбомный экран и не пересекают лотки.

Отдельно, если установлен Chrome: `npm run build` и `npm run test:smoke` (мобильный размер окна, пауза, поворот, повторная загрузка без сети).

Вручную на настоящем телефоне стоит проверить:

- установку на главный экран;
- вырезы экрана и жесты системы;
- вибрацию;
- удобство кнопок большим пальцем;
- реальный режим полёта после установки.
